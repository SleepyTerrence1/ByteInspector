# ByteInspector
ByteInspector is a python written application designed to do a couple of things. 
These things may include reading a file, checking a files integrity, etc. ByteInspector
is designed to do these things efficiently and fast as possible.
# Features
- Easy to navigate main menu
- able to read files and images
- displays files or images in hex
- displays files or images in ascii
- displays offset
- able to compare two files
- able to find a specific content within files
- 2 test images if you want to try it yourself.
# What I learned
- Firstly, I learned how to access specific files within a computer then access and 
read it's contents fast and efficiently using the python in-built functions
.tell() and .seek()
- I have learned how to implement proper error catching using pythons try and exception
blocks.
- I have learned files have specific signatures that are used to identify them.
# Running the Project
1. Install Python3 if you haven't already, make sure its version 3.12.3 or later. `python3 --version` for Linux/MacOS and `python --version` for Windows
2. run `git clone https://github.com/SleepyTerrence1/ByteInspector.git` into a terminal
2. enter the project directory `cd ByteInspector`
3. Run the application `python3 Main.py` for Linux/MacOS, `python Main.py` for Windows
